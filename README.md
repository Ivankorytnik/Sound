# Speech Recognition MVP

Статический MVP для распознавания речи из загруженного аудио/видео файла прямо в браузере.

## Что есть

- drag-and-drop загрузка файла;
- распознавание через Whisper в браузере;
- русский, английский или автоопределение языка;
- Whisper Tiny / Base;
- таймкоды сегментов;
- редактирование результата;
- копирование текста;
- скачивание `.txt`;
- API-ключ и backend не нужны.

## Запуск локально

ES-модули лучше открывать через локальный HTTP-сервер, а не двойным кликом по `index.html`.

```bash
python3 -m http.server 8000
```

Затем открыть `http://localhost:8000`.

## GitHub Pages

1. Положить `index.html`, `styles.css`, `app.js` в отдельную папку репозитория, например `speech/`.
2. Закоммитить и отправить в GitHub.
3. Если GitHub Pages уже включён, страница будет доступна по адресу вида:
   `https://USERNAME.github.io/REPOSITORY/speech/`

Если репозиторий пользователя называется `USERNAME.github.io`, адрес будет:
`https://USERNAME.github.io/speech/`.

## Важно

При первом запуске браузер скачивает файлы выбранной модели Whisper. Размер и скорость зависят от модели и устройства. Для первого MVP лучше начинать с Whisper Tiny.

Поддержка контейнеров и кодеков зависит от браузера. Наиболее надёжные форматы: MP3 и WAV. M4A/WEBM обычно работают в современных браузерах, но зависят от кодека.
