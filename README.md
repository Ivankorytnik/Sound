## Что было изменено в v1.2.0

Главная цель версии — вернуть качество обычных длинных записей без зависания интерфейса.

- `Авто` больше не переводит запись длиннее 5 минут на Whisper Tiny.
- `Авто` = профиль **БАЛАНС** и **Whisper Base**.
- `БЫСТРО` = Whisper Tiny; этот режим нужно выбирать вручную, когда важнее скорость, чем точность.
- `ТОЧНО` = Base с более короткими чанками, перекрытием 2 секунды и точными сегментными таймкодами.
- `ШУМ` = режим для старых, музыкальных и плохих записей.
- В БАЛАНС запись идёт блоками по ~28 секунд с перекрытием 1.5 секунды.
- Перекрытия объединяются с удалением дублей на границах.
- Убран жёсткий `no_repeat_ngram_size=3` из чистых режимов: он мог искажать естественно повторённые слова.
- Жёсткая защита от повторов остаётся только для режима ШУМ и пост-фильтра.
- Whisper по-прежнему работает в отдельном Web Worker, поэтому интерфейс не должен блокироваться.
- На WASM/CPU используется q8, на WebGPU — облегчённая конфигурация декодера.
- Распознанный текст появляется **частями во время обработки**, а не только после окончания 19-минутного файла.
- После каждого блока показываются прогресс, фактическая скорость и оценка оставшегося времени.

## Рекомендуемые настройки для обычного разговора

- Язык: **Русский**
- Модель: **Авто**
- Качество: **Авто · БАЛАНС** (Small на WebGPU, Base на CPU/WASM)
- Защита от ошибок: **Обычная** или **Строгая**

Если запись чистая и 10–30 минут, сначала используй БАЛАНС. Tiny нужен только когда приоритет — максимально быстро получить черновик.

## Режимы

### Файл
Загрузка MP3/WAV/M4A/WEBM/MP4 и распознавание через Worker.

### Диктофон
Запись микрофона, таймер, сохранение аудио и автоматическое распознавание после остановки.

### Живой разговор
Локальный захват разрешённого браузером аудио источника и микрофона. Системные разрешения и индикаторы браузера/ОС не обходятся.

## Результат

- редактируемый текст;
- копирование в буфер;
- TXT;
- Excel `.xlsx`;
- список сегментов и таймкодов;
- версия и дата сборки отображаются в интерфейсе.

## Развёртывание

Проект статический и подходит для GitHub Pages. Для доступа к микрофону и `getDisplayMedia()` нужен HTTPS (GitHub Pages его предоставляет).

## v1.5.0 — качество распознавания и устойчивый захват (21.08.2026 06:50)

Исправлен сценарий, при котором интерфейс показывал `ОШИБКА ЗАХВАТА`, а оба источника оставались `не подключён`.

Что изменено:
- основной `app.js` больше не импортирует Transformers.js при открытии страницы; меню и захват работают независимо от AI/CDN;
- `НАЙТИ И НАЧАТЬ` вызывает `getDisplayMedia()` с запросом аудио и `systemAudio: include`;
- системный звук и микрофон подключаются независимо, поэтому ошибка одного источника не скрывает состояние второго;
- добавлена диагностика: отдельные сообщения для отмены системного окна, запрещённого микрофона, выбранной вкладки без `Share tab audio`, окна/экрана без системной аудиодорожки;
- добавлены кнопки `ПОВТОРИТЬ: ВКЛАДКА СО ЗВУКОМ` и `ПРОВЕРИТЬ МИКРОФОН`;
- если системный звук не получен, но микрофон доступен, Speech Lab может начать запись только микрофона и явно предупреждает об этом;
- при успешном подключении звук встречи и микрофон смешиваются через Web Audio API и записываются MediaRecorder;
- при завершении демонстрации браузером запись корректно останавливается;
- диктофон, загрузка файла, Worker-распознавание, копирование текста, TXT и Excel сохранены.

### Если нужен звук Zoom / Толк

Для веб-версии встречи выбирай `Вкладка браузера` и в системном окне Chrome/Edge включай `Также передавать аудио вкладки` / `Share tab audio`. Для десктопного Zoom поддержка системного звука при выборе окна/экрана зависит от ОС и браузера.

## Качество распознавания v1.5.0

- В режиме **Авто / Баланс**: Whisper Small на WebGPU, Whisper Base на CPU/WASM.
- В режиме **Точно**: Whisper Large-v3-Turbo на WebGPU; если GPU недоступен, автоматический fallback.
- В режиме **Максимум**: Large-v3-Turbo + более широкое перекрытие чанков + повторная проверка подозрительных фрагментов.
- Русский язык лучше фиксировать вручную, если запись русскоязычная.
- Чанки не превышают 29 секунд, чтобы избежать проблем с 30-секундной границей timestamp-режима.
- Добавлена мягкая нормализация тихого аудио и более устойчивое удаление дублей на стыках.
- Tiny используется только в режиме **Быстро** и не выбирается автоматически для обычной записи.
