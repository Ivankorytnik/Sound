# Speech Lab MVP

**Версия:** `v1.0.0`  
**Сборка:** `20.08.2026 07:31`

Локальный браузерный MVP для распознавания аудио/видео и записи звука интернет-встреч.

## Функции результата и диктофона

- кнопка `СКОПИРОВАТЬ ТЕКСТ` копирует текущий отредактированный текст в буфер обмена;
- кнопка `ВЫГРУЗИТЬ В EXCEL` создаёт настоящий `.xlsx` с листами `Текст` и `Сегменты`;
- Excel формируется в браузере; если основной модуль недоступен, приложение пробует резервный XLSX-экспорт, затем Excel-совместимый CSV;
- режим `ДИКТОФОН` записывает только микрофон;
- после `ОСТАНОВИТЬ` запись можно прослушать, скачать и автоматически распознать;
- версия и дата/время сборки отображаются в шапке и подвале сайта, а также попадают в Excel.

## Что изменено в версии Performance

Главная проблема предыдущей версии — Whisper запускался в основном потоке браузера. На тяжёлых моделях вкладка могла показывать «Страница не отвечает».

Теперь:

- распознавание выполняется в `transcription-worker.js` — отдельном Web Worker;
- интерфейс остаётся отзывчивым во время инференса;
- при наличии WebGPU приложение сначала пытается использовать GPU;
- если WebGPU недоступен или модель на нём не запустилась, есть автоматический fallback на WASM в Worker;
- модель по умолчанию — `Авто`;
- на CPU/WASM длинные записи автоматически используют Whisper Tiny, чтобы не считать Whisper Small часами;
- на WebGPU и для обычных записей используется Whisper Base;
- Whisper Small оставлен только как ручной тяжёлый режим;
- аудио обрабатывается кусками с отображением реального прогресса;
- можно остановить распознавание кнопкой `ОСТАНОВИТЬ`;
- есть простая VAD-фильтрация тишины и фильтр повторов/зацикливаний.

## Рекомендованные настройки

### Обычные записи

- Модель: `Авто`
- Качество: `Авто / обычная · баланс`
- Защита от ошибок: `Строгая` или `Обычная`

### Старая/шумная запись

- Модель: `Авто` или `Whisper Base`
- Качество: `Старая / шумная · точнее, медленнее`
- Защита от ошибок: `Строгая`

### Очень длинная запись на ноутбуке без WebGPU

- Модель: `Авто` или `Whisper Tiny`
- Качество: `Авто / обычная · баланс`

Whisper Small в браузере на CPU использовать для часовых записей не рекомендуется: Worker не даст интерфейсу зависнуть, но сама модель всё равно будет считать долго.

## Живой захват

1. Открой Zoom / Толк / Meet.
2. Открой `ЖИВОЙ РАЗГОВОР`.
3. Нажми `НАЙТИ И НАЧАТЬ`.
4. В системном диалоге браузера выбери вкладку/окно/экран и включи передачу аудио.
5. После остановки запись остаётся локально в браузере.
6. При включённом `РАСПОЗНАТЬ ПОСЛЕ СТОПА` автоматически запускается Worker-распознавание.

Браузер всегда сам показывает системный диалог выбора источника. Этот MVP не скрывает и не обходит системные индикаторы захвата.

## GitHub Pages

Положи все файлы в одну папку. Важно: `transcription-worker.js` должен лежать рядом с `app.js`, иначе распознавание не запустится.

Пример:

```text
/speech/
  index.html
  styles.css
  app.js
  transcription-worker.js
  site.webmanifest
  ...favicon files
```

Страница должна работать по HTTPS (GitHub Pages подходит).

## Почему первый запуск всё ещё может быть долгим

Модель Whisper скачивается из Hugging Face при первом использовании. После этого браузер обычно использует кэш. Время самой расшифровки зависит от длины записи, модели и наличия WebGPU. Главное изменение этой версии: тяжёлый инференс больше не блокирует UI и браузер не должен считать страницу зависшей.
