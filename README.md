# Speech Lab MVP

MVP для локального распознавания речи в браузере на Whisper/Transformers.js.

## Что умеет

- Распознаёт речь из загруженных аудио/видеофайлов.
- Захватывает звук интернет-встречи во время звонка через Screen Capture API.
- Подходит для Zoom Web, Толк, Google Meet и других звонков, если браузер отдаёт аудиодорожку выбранной вкладки/экрана.
- Опционально добавляет микрофон пользователя в ту же запись.
- После остановки может автоматически запустить локальное распознавание Whisper.
- Показывает таймкоды, даёт редактировать, копировать и скачивать текст.
- API-ключ и backend не нужны.

## Как использовать живой захват

1. Открой встречу Zoom / Толк / Meet.
2. В Speech Lab выбери `ЖИВОЙ РАЗГОВОР`.
3. Оставь `ДОБАВИТЬ МОЙ МИКРОФОН`, если нужен и твой голос.
4. Нажми `НАЧАТЬ ЗАХВАТ`.
5. В системном окне браузера выбери вкладку/окно/экран со звонком.
6. Обязательно включи `Поделиться аудио` / `Share audio`, если такая опция показана.
7. Иди на звонок. Страница будет записывать аудио.
8. Вернись и нажми `ОСТАНОВИТЬ И СОХРАНИТЬ` либо останови демонстрацию средствами браузера.
9. Если включён автозапуск, Whisper начнёт расшифровку автоматически.

## Важные ограничения браузера

- `getDisplayMedia()` работает только в защищённом контексте (HTTPS; localhost также подходит для разработки).
- Пользователь обязан вручную подтвердить захват и выбрать источник. Страница не может тайно подключиться к Zoom/Толк.
- Наличие системной аудиодорожки зависит от браузера, ОС и выбранного источника. Если браузер не отдал audio track, приложение попросит повторить выбор с включённым `Share audio`.
- Для браузерных встреч обычно удобнее выбирать именно вкладку со встречей.
- Для desktop-приложения Zoom возможность захвата его звука зависит от того, позволяет ли текущий браузер/ОС делиться системным аудио.


## Модели

По умолчанию доступны:

- `Xenova/whisper-tiny` — быстрее.
- `Xenova/whisper-base` — тяжелее, но обычно точнее.

Первая загрузка модели требует интернет-соединения и может занять заметный объём браузерного кэша.
