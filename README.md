# Speech Lab v1.1.0

Сборка: **20.08.2026 07:49**

Локальный MVP распознавания речи для GitHub Pages: файл, диктофон и захват звука встречи.

## Что исправлено в v1.1.0

Главная цель этой сборки — длинные обычные записи не должны блокировать вкладку браузера.

- Whisper запускается в отдельном `Web Worker`.
- Декодирование и ресэмплинг аудио больше не выполняются тяжёлым JavaScript-циклом по всем сэмплам. Используется нативный `OfflineAudioContext`.
- Float32-аудио передаётся в Worker как transferable `ArrayBuffer`, без второй большой копии.
- Режим **Авто** для записей от 5 минут автоматически включает FAST-пайплайн.
- Для длинной чистой записи в Auto используется `Whisper Tiny`.
- При WebGPU используется WebGPU, при ошибке — автоматический fallback на WASM/CPU.
- В FAST-пайплайне используются блоки около 29 секунд без перекрытия.
- Дорогие точные timestamp-вычисления отключены в FAST: таймкоды остаются на уровне блоков.
- Тишина пропускается по лёгкому RMS/VAD.
- После первого блока показывается реальная оценка оставшегося времени и коэффициент скорости.
- Кнопка «РАСПОЗНАТЬ РЕЧЬ» во время обработки превращается в «ОСТАНОВИТЬ» и завершает Worker.

## Как распознавать обычную запись на 19 минут

Оставь настройки:

- **Модель:** Авто
- **Качество:** Авто · длинные записи ускоряются
- **Защита от ошибок:** Строгая или Обычная
- **Язык:** Русский, если запись русская

Speech Lab сам выберет FAST + Whisper Tiny для длинной записи. Если нужен более точный второй проход по важному короткому фрагменту, выбери Base и «Точнее» только для этого фрагмента.

## Режимы

- **Из файла** — MP3/WAV/M4A/OGG/WEBM/MP4, если браузер умеет декодировать кодек.
- **Диктофон** — локальная запись с микрофона и автотранскрибация после Stop.
- **Живой разговор** — захват аудио выбранной вкладки/окна + опционально микрофона. Системное окно выбора источника браузер показывает при каждом запуске.

## Результат

- редактируемый текст;
- копирование в буфер обмена;
- TXT;
- Excel `.xlsx` (библиотека SheetJS загружается только при нажатии кнопки Excel);
- сегменты и таймкоды;
- скачивание локальной записи диктофона/встречи.

## Запуск

Проект не требует сборщика. Загрузи все файлы одной папкой на GitHub Pages и открывай `index.html` через HTTPS.

При первом распознавании модель скачивается с Hugging Face и кэшируется браузером. Первый запуск поэтому дольше повторных.
