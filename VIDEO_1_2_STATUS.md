# Speech Lab 1.2: запись экрана

Реализовано 11.11.2026 для `video.html`. Остальные режимы и настройки Whisper не изменяются.

## Возможности

- Три источника: локальный файл, запись экрана, прямая ссылка.
- Выбор вкладки, окна или экрана через системный диалог `getDisplayMedia`.
- Звук источника по умолчанию включён; микрофон по умолчанию выключен.
- Выбор микрофона, реальные индикаторы наличия аудиодорожек, уведомление об отсутствии звука.
- Микрофон и звук источника смешиваются Web Audio в одну дорожку без вывода на динамики.
- MediaRecorder: WebM VP8/Opus при поддержке; проверяемые резервные MIME, включая MP4.
- Пауза/продолжение, таймер без пауз, беззвучный предпросмотр захватываемого изображения.
- После остановки: просмотр, скачивание исходного видео, существующее извлечение MP3/M4A и Whisper, TXT/SRT.
- Видео без аудио можно скачать; распознавание и извлечение аудио отключены.
- Остановка демонстрации и отключение аудиоустройства завершают запись; дорожки и AudioContext освобождаются.
- Отмена ожидающего диалога освобождает потоки, даже если разрешение выдаётся позже.
- Переключение режима/источника и обработка блокируются во время записи.
- Начало новой записи требует подтверждения замены, если предыдущая не передана браузеру для скачивания.
- Возврат в режим записи восстанавливает её как выбранный файл.
- Перед закрытием страницы с активной/нескачанной записью запрашивается стандартное подтверждение браузера.

## Ограничения

- Нужен HTTPS и браузер с поддержкой захвата экрана и MediaRecorder; основной ручной сценарий: настольные Chrome/Edge.
- Запись звука окна/экрана зависит от ОС и браузера; приложение не может принудительно получить отсутствующую аудиодорожку.
- Запись находится в памяти браузера. Для долговременного хранения нужно скачать видео.
- Автоостановка: 90 минут активной записи или 280 МиБ накопленных блоков. Последний блок может увеличить размер. Файл свыше существующего лимита обработки 300 МиБ доступен отдельной кнопкой скачивания, но не передаётся в FFmpeg/Whisper.
- Разрешение/битрейт запрашиваются как предпочтения браузеру; фиксированное качество не гарантируется.
- Запись экрана не использует внешних платных API. Существующее скачивание FFmpeg и модели при первом распознавании сохраняется.

## Проверки

`video_recorder_test.py`: подменяется только получение источника, используется настоящий MediaRecorder, Web Audio и FFprobe. Проверяются две независимые частоты в смешанном аудио, скачивание воспроизводимого видео, пауза, остановка демонстрации во время паузы, отсутствие аудио, микрофон без звука источника, отказ в разрешениях, отмена ожидающего диалога, освобождение всех дорожек, восстановление записи, отсутствие горизонтального переполнения.

Существующие `video_smoke_test.py`, `video_url_test.py`, `video_e2e_test.py`, `compact_smoke_test.py` проверяют прежние сценарии. Новый тест включён в GitHub Actions.

Системный диалог и получение аудио конкретной ОС требуют ручной проверки на целевом компьютере: вкладка со звуком, окно Teams/Zoom, весь экран; затем микрофон, пауза, остановка, скачивание и распознавание.
